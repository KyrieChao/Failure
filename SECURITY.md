# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it to us privately via email at:
**[chao893760@163.com]**

Please do not open a public issue on GitHub for security vulnerabilities. We will investigate and fix the issue as soon as possible, and coordinate a release with you.

We appreciate your efforts to responsibly disclose your findings, and will make every effort to acknowledge your contributions.
